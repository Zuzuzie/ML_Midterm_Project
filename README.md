# ML_Midterm_Project
Repository for midterm tasks
Dataset name: Spotify Song Popularity
Source: https://www.kaggle.com/datasets/anbudanadithya/spotify-music
license: MIT
This dataset contains information about thousands of Spotify tracks, including various audio features and metadata such as popularity, artist information, and musical characteristics. The dataset includes both numerical and categorical variables that describe each track’s attributes and performance.

We selected this dataset for several reasons. First, it satisfies the project requirements, as it contains more than 500 observations (about 114000) and multiple features(21 columns), including a suitable target variable (song popularity) for supervised learning tasks. This makes it appropriate for both regression and classification problems.

Second, the dataset is well-structured and suitable for exploratory data analysis. It includes meaningful variables such as tempo, energy, danceability, and loudness, which allow for insightful visualisations and pattern discovery. These features are also useful for building predictive models and understanding relationships between musical characteristics and popularity.

Third, the dataset is ideal for unsupervised learning. The audio features can be used to group songs into clusters, enabling meaningful segmentation such as identifying similar types of music or patterns in listening preferences.

Finally, the topic is intuitive and relevant, making it easier to interpret results and present findings clearly. Music popularity is a real-world problem, and analyzing it provides practical insights into how different attributes influence the success of a track.
